# Монтаж рилсов на MacBook: Claude Code + ffmpeg + Whisper

Всё работает на вашем компьютере. Платных API и водяных знаков нет. Исходники не изменяются.
Дата проверки источников: 6 ноября 2026.

## Что проверено, а что нет

| Что | Статус |
|---|---|
| Скрипты нарезки, субтитров, экспорта 1080x1920, определения ритма | Запущены и проверены на тестовых файлах в облачном Linux |
| Распознавание русской речи | Проверено на синтетической речи (faster-whisper, модель `small`). На настоящей речи и на Mac не проверялось |
| `setup_mac.sh`, mlx-whisper на вашем MacBook | **Не проверялось** (у меня нет доступа к вашему Mac). Если установка упала, покажите ошибку Claude Code |
| Обработка HDR-видео с iPhone | Цепочка перевода цветов написана, на настоящем HDR-файле не проверялась |
| Выбор мыслей | Только по расшифровке (текст). Картинку Claude оценивает лишь по кадрам-превью, которые сам прочитал |

## Папки

```
reels-kit/
  sources/   ← ваши исходники с iPhone (копии; оригиналы остаются на iPhone). Скрипты их не меняют
  fonts/     ← шрифты (уже лежит Montserrat ExtraBold, кириллица, свободная лицензия OFL)
  music/     ← музыка для рилса с мероприятия (файл mp3/m4a)
  plans/     ← планы нарезки (пишет Claude)
  work/      ← расшифровки, превью (можно удалять)
  output/    ← готовые MP4 9:16 и субтитры .srt
```

## Настройка (один раз)

1. Скачайте папку `reels-kit` на Mac и положите в «Документы». Если папка в GitHub-репозитории `lizalogia/Elizaveta`, на ветке `claude/confident-bell-4q4ojt`: зелёная кнопка Code → Download ZIP.
2. Откройте программу «Терминал» (Cmd+Пробел, наберите «Терминал»).
3. Установите Homebrew, если его нет: проверьте командой `brew --version`. Если команда не найдена, возьмите установочную строку на сайте https://brew.sh, вставьте в Терминал и нажмите Enter. Homebrew — это установщик программ для Mac.
4. Перейдите в папку (подставьте свой путь): `cd ~/Documents/reels-kit`
5. Запустите установку: `bash setup_mac.sh`
   Скрипт поставит ffmpeg (резка видео), Python-окружение, mlx-whisper (распознавание речи) и Pillow (рисование субтитров).
6. Модель распознавания (`whisper-large-v3-turbo`, **около 1,6 ГБ** по данным сторонних руководств, с официальной страницы не сверялось) скачается один раз при первой расшифровке. Нужен интернет и 2–3 ГБ свободного места. По тем же руководствам на M1 с 16 ГБ она работает свободно. Сколько у вас ОЗУ: меню Apple → «Об этом Mac».
7. Откройте приложение Claude → вкладка Code → выберите папку `reels-kit` как рабочую. Файл `CLAUDE.md` в ней Claude Code прочитает сам. (Точные названия кнопок в вашей версии приложения я не проверял.)

Плагины, MCP и скиллы **не нужны**: всё делают обычные скрипты.

## Как перенести видео с iPhone

1. Выберите ролик в «Фото» → «Поделиться» → AirDrop → ваш Mac. Или на Mac в приложении «Фото»: Файл → Экспортировать → «Экспортировать неизмененный оригинал».
2. Положите файл в `reels-kit/sources/`. Оригинал на iPhone не удаляйте.
3. HDR: iPhone по умолчанию может снимать HDR (Настройки → Камера → Запись видео → «HDR-видео»; название пункта в вашей iOS не проверял). Скрипт пробует перевести HDR в обычные цвета, но проверьте цвета на результате. Для важной съёмки можно выключить HDR заранее.

## Сценарий 1. Экспертный рилс с русскими субтитрами

Напишите Claude Code (замените имя файла):

```
Смонтируй экспертный рилс из sources/МОЙ_ФАЙЛ.mov по инструкции в CLAUDE.md.
1) Сделай расшифровку (transcribe.py), покажи мне текст.
2) Найди одну главную мысль. Крючок в первые 2-3 секунды, затем суть, затем короткий вывод.
   Убери паузы, «э-э», «ну», оговорки и повторы (оставь лучший дубль). Итог до 60 секунд.
   Не меняй смысл и не начинай фразу с середины предложения.
3) Напиши план в plans/, собери ролик (render_expert.py) с русскими субтитрами.
4) Проверь результат (check_output.py), посмотри кадры-превью.
5) Скажи прямо: что ты оценивал по тексту, что по кадрам, а что я должен проверить сам.
   Выбор мысли делай по расшифровке и не утверждай, что оценил картинку, если не смотрел кадры.
```

Если в речи много терминов, добавьте: «при расшифровке используй --prompt "термин1, термин2"».

## Сценарий 2. Рилс с мероприятия под музыку

Положите трек в `music/`. Нужен именно файл: трендовый звук из Instagram скачать нельзя. Берите трек, на который у вас есть права (условия смотрите на странице трека). Либо соберите ролик под ваш трек и добавьте трендовый звук в самом Instagram при публикации; тогда попадание в ритм будет не гарантировано.

```
Собери рилс с мероприятия из sources/МОЙ_ФАЙЛ1.mov и sources/МОЙ_ФАЙЛ2.mov под music/ТРЕК.mp3, 20-30 секунд.
1) Для каждого исходника сделай contact_sheet.py (кадры раз в 1 сек) и посмотри листы.
2) Найди ритм: beats.py music/ТРЕК.mp3. Скажи темп и проверь, что он правдоподобен.
3) Выбери самые удачные моменты по кадрам-превью: чёткие, с людьми и эмоцией, без смазанных
   и пустых кадров; чередуй общие и крупные планы. Длины кадров по 2-4 доли, ближе к концу короче.
4) Напиши план в plans/ и собери render_event.py. Проверь check_output.py.
5) Скажи прямо: ты видел только кадры раз в секунду, движения и звука исходника не видел.
   Что мне проверить вручную (кадрирование, лица на краю, попадание в музыку)?
```

## Что проверить вручную всегда

1. **Смысл после сокращения**: не потерялось ли «не», не изменился ли вывод, нет ли склейки посреди мысли.
2. **Субтитры**: имена, термины, окончания. В тесте модель `small` написала «кожи» вместо «коже». Файл `.srt` лежит рядом с видео. Исправить текст можно у Claude Code: «в субтитрах замени X на Y и пересобери».
3. **Кадрирование 9:16**: если исходник горизонтальный, берётся центр (`--crop-x 0.5`). Если человек не по центру, скажите: «сдвинь кадр левее».
4. **Выбор кадров**: Claude смотрел только превью раз в секунду. Просмотрите ролик целиком на телефоне.
5. **Музыка**: попадание смены кадров в доли (ошибка определения у меня на тесте была около 0,04 с, на реальной музыке может быть больше; на плавной музыке без ударов или на «двойном» темпе возможны сбои) и права на трек.
6. **Громкость и цвета** на телефоне перед публикацией.

## Ограничения

- Лимиты Claude Pro общие и ограничены. Точные цифры не проверял. Тяжёлая работа (расшифровка, кодирование) идёт на вашем Mac и из лимита не расходуется, расходуется только общение с Claude.
- Рилс до 60 секунд из исходника 2–3 минуты собирается за минуты. Точное время на вашем Mac не измерялось.
- CapCut и VN не нужны. Их можно использовать для финальных правок, но ограничения их бесплатных версий я не проверял.
